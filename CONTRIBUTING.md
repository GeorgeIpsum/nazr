# Contributing

## Toolchain

- Node 22 (`.node-version`) and pnpm 10
- Go 1.26
- Docker (compose smoke test, API tests that start Postgres)
- Terraform 1.14 and tflint (only for `deploy/terraform`)

## Commands

Run from the repository root:

```bash
pnpm install
pnpm lint            # per-package linters (Biome, gofmt, go vet, staticcheck)
pnpm lint:biome      # Biome across the whole repo
pnpm typecheck
pnpm test
pnpm build
```

- `pnpm --filter @nazr/api test` runs the Go tests. They need Docker, or set `NAZR_TEST_DATABASE_URL` to an existing PostgreSQL.
- `pnpm --filter @nazr/demo test:e2e` runs the Playwright end-to-end tests.
- `pnpm smoke:compose` brings up the compose stack and runs the smoke script (needs Docker, `curl`, `jq`).

## Fixtures

The Go API tests use client request fixtures generated by the client package. After changing client components, regenerate them and commit the result:

```bash
pnpm --filter @nazr/thumbmark fixtures
```

CI re-runs the generator and fails if `apps/api/testdata/fixtures` differs.

## Syncing upstream

`packages/thumbmark` is a fork of ThumbmarkJS; the synced tag is in `packages/thumbmark/UPSTREAM`. To see what changed upstream relative to this fork:

```bash
pnpm --filter @nazr/thumbmark upstream:diff [tag]
```

It clones the tag, normalises it with this repo's Biome config so the diff is not formatting noise, and prints a unified diff. It is an inspection tool; apply changes by hand and update `UPSTREAM`.

## Commits

`type(scope): subject`, with type one of `feat`, `fix`, `chore`, `docs`, `test` and scope one of `thumbmark`, `api`, `demo`, `deploy`, `docs`, `ci`. Example: `fix(api): cache visitor totals per key`.
