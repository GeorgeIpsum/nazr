# nazr Plan 2: Go API

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `nazr` Go binary: a ThumbmarkJS-wire-compatible fingerprinting API that terminates TLS, captures JA4/JA3, HTTP/2 and JA4H fingerprints, enriches with IP intelligence (MaxMind, Apple Private Relay, Tor, datacenter, VPN), resolves visitors in Postgres, and classifies risk.

**Architecture:** One module at `apps/api`, one `internal/` package per concern with small interfaces (spec section 3.1). Pure parsers (`tlsfp`, `h2fp`, `httpfp`, `fingerprint`, `jsnum`, `classify`) have no I/O and are tested against byte captures and golden fixtures. `conn` wraps the listener and attaches a per-connection holder to request contexts. `server` composes everything behind `net/http`'s standard mux.

**Tech Stack:** Go 1.26, `net/http` ServeMux, `golang.org/x/net/http2` (+ `hpack`), `golang.org/x/crypto/acme/autocert`, `github.com/jackc/pgx/v5`, `github.com/pressly/goose/v3`, `github.com/redis/go-redis/v9`, `github.com/oschwald/maxminddb-golang/v2`, `github.com/gaissmai/bart`, `github.com/oklog/ulid/v2`, `github.com/pires/go-proxyproto`, `github.com/caarlos0/env/v11`, `github.com/prometheus/client_golang`, `github.com/testcontainers/testcontainers-go` (postgres module), `staticcheck` via `go tool`.

**Spec:** `docs/superpowers/specs/2026-10-21-nazr-design.md`

## Global Constraints

- Module path `nazr/api`; `go.work` at repo root lists `./apps/api`. Go `1.26` in `go.mod`.
- Config comes only from `NAZR_*` environment variables (spec section 15). Defaults verbatim: `LISTEN_ADDR=:443`, `HTTP_ADDR=:80`, `METRICS_ADDR=127.0.0.1:9090`, `TLS_MODE=terminate`, `JA4_HEADER=x-ja4`, `CLIENT_IP_HEADER=x-forwarded-for`, `DEFAULT_RATE_LIMIT=600`, `BODY_LIMIT=262144`, `DATA_DIR=/data`, `AUTO_MIGRATE=true`, `LOG_LEVEL=info`, `LOG_FORMAT=json`, `MAXMIND_EDITIONS=GeoLite2-City,GeoLite2-ASN`, `VISITOR_MATCH_WINDOW=720h`, `STORE_IP=raw`, `STORE_COMPONENTS=false`, `EVENT_RETENTION=2160h`, `UA_JA4_MIN_OBSERVATIONS=20`, `COLLECT_SAMPLE_RATE=0.01`, `CORS_ORIGINS=*`.
- Every error response body is `{"error": "<code>", "message": "<text>"}` with codes: `bad_request`, `payload_too_large`, `unauthorized`, `key_revoked`, `origin_not_allowed`, `rate_limited`, `store_unavailable`, `internal`.
- Fingerprint capture never fails a request; absence is represented by a nil pointer and an omitted component.
- Thumbmark hash is murmur3 x86 128-bit, hex of the 16 output bytes in little-endian word order, over `StableStringify(merged)`; must match `apps/api/testdata/fixtures/stringify.json`.
- API keys: `nzr_` + 32 random bytes base32 (lowercase, no padding); stored as SHA-256 hex; display prefix is the first 8 characters after `nzr_`.
- IDs (visitor, request) are ULIDs, lowercase Crockford base32 as `ulid.ULID.String()` produces uppercase; store and return uppercase.
- Logging through `log/slog` only. No global state except Prometheus registry.
- `gofmt -l`, `go vet`, and `go tool staticcheck` are clean at every commit.

## Review Focus

1. Plaintext HTTP or garbage bytes on the TLS listener must close the connection without panic or hang, and the server must keep serving. Pinned in Task 7.
2. Client components with unicode keys, non-ASCII strings, floats like `0.1`/`1e21`, and nested arrays must hash identically to the TypeScript client. Pinned in Tasks 2 and 3 via fixtures.
3. A `visitorId` from another API key, or a malformed ULID, must never be reused; the request gets a fresh visitor. Pinned in Task 11.
4. IPv4-mapped IPv6 remote addresses (`::ffff:1.2.3.4`) must be looked up as IPv4 and reported as `v4`. Pinned in Task 8.
5. A MaxMind 401 or a download that fails mid-stream must leave the previously loaded table in place and the server serving; `/readyz` must still return 200 with that source marked not loaded. Pinned in Tasks 8 and 13.

  - `type Result struct { Settings []Setting; WindowUpdate uint32; Priorities []Priority; PseudoHeaderOrder []string; HeaderOrder []string; Fingerprint string }`
  - `h2fp.NewParser(limit int) *Parser`; `(p *Parser) Feed(b []byte) (done bool)` consumes bytes (preface then frames) and reports done after the first `HEADERS` frame with `END_HEADERS`, or after `limit` bytes, or on a parse error; `(p *Parser) Result() (*Result, bool)` returns the result when at least `SETTINGS` was seen.

Displayed `weight` is the wire weight plus 1 (RFC 7540 encodes 1..256 as 0..255), which is why Firefox shows `201`, `101`, `1`, `241`.
